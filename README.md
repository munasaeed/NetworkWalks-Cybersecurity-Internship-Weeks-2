# NetworkWalks Cybersecurity Internship — Week 2

Footprinting, OSINT and Network Scanning

Welcome to my Week 2 practical work as part of the NetworkWalks Cybersecurity Internship 2026.

This repository documents my hands-on learning experience in cybersecurity, focusing on information gathering, footprinting, Open-Source Intelligence (OSINT), and network scanning.

## Project Overview

During this week, I explored cybersecurity tools to understand how information about domains, web technologies, DNS infrastructure, and network devices can be collected and analyzed.

## Tools and Practical Activities

### 1. Kali Linux — Footprinting

I used six tools to examine the assigned domain, networkwalks.com:

* WHOIS: Retrieved domain registration information.
* WhatWeb: Identified web technologies and server information.
* Nslookup: Checked domain name resolution.
* cURL: Examined HTTP response headers and redirects.
* WAFW00F: Identified the presence of a web application firewall.
* DNSRecon: Gathered DNS records and infrastructure information.

### 2. Maltego — Visual Footprinting

I performed an introductory OSINT exercise using Maltego Graph Desktop.

Activities included:

* Creating a domain entity.
* Exploring related hostnames.
* Identifying associated IP address information.
* Visualizing relationships through a link-analysis graph.

### 3. Zenmap — Network Scanning

I used Zenmap, the graphical interface for Nmap, to perform network scanning exercises.

Activities included:

* Scanning a Windows computer.
* Identifying open and closed ports.
* Performing local network host discovery.
* Examining and saving scan results.

## Key Learning Outcomes

Through these exercises, I gained practical experience in:

* Footprinting and reconnaissance fundamentals.
* Using command-line tools in Kali Linux.
* Exploring domain and DNS information.
* Understanding basic OSINT and relationship mapping.
* Identifying network hosts and open ports.
* Interpreting and documenting technical findings.
* Organizing cybersecurity evidence and reports.
